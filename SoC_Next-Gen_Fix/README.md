# SoC Next-Gen Fix

**Мод для S.T.A.L.K.E.R.: Shadow of Chernobyl**  
*Версия: 1.0.0*

Оптимизация, стабильность и улучшенная графика для классической игры Stalker SoC.

---

## 📋 Описание

SoC Next-Gen Fix — это комплексный мод, направленный на:
- **Исправление вылетов и утечек памяти** оригинальной игры
- **Оптимизацию производительности** для современных ПК
- **Улучшение графики** с сохранением стиля оригинала
- **Реалистичную погоду** с сезонными изменениями

---

## ⚙️ Требования

### Минимальные:
- S.T.A.L.K.E.R.: Shadow of Chernobyl (оригинальная версия 1.0006)
- Windows 7/8/10/11 (x64)
- 2 GB VRAM
- 4 GB RAM
- DirectX 9.0c совместимая видеокарта

### Рекомендуемые:
- **OGSR Engine** или **OpenXRay** (для полной поддержки многопоточности и DirectX 11)
- 4GB Patch (для использования > 2GB RAM)
- 4 GB VRAM
- 8 GB RAM

---

## 📦 Установка

### Базовая установка:
1. Скопируйте папку `gamedata` из архива в директорию с игрой
   ```
   C:\Games\S.T.A.L.K.E.R. - Shadow of Chernobyl\gamedata
   ```
2. Запустите игру

### Для максимальной совместимости:
1. Установите **OGSR Engine** (рекомендуется) или **OpenXRay**
2. Примените **4GB Patch** к xrEngine.exe
3. Скопируйте `gamedata` из мода
4. Выберите пресет графики (см. ниже)

---

## 🎮 Пресеты графики

Мод включает 4 пресета для разных конфигураций ПК:

| Пресет | Файл | VRAM | Описание |
|--------|------|------|----------|
| **Low** | `render_low.ltx` | < 2GB | Минимальная графика, максимальный FPS |
| **Medium** | `render_medium.ltx` | 2-4GB | Баланс качества и производительности |
| **High** | `render_high.ltx` | > 4GB | Максимальное качество |
| **Default** | `render.ltx` | Любой | Настройки по умолчанию |

### Как применить пресет:
1. Откройте файл выбранного пресета (`render_*.ltx`)
2. Скопируйте содержимое секции `[render]`
3. Вставьте в `render.ltx` (заменив текущие настройки)

Или используйте лаунчер для автоматического переключения.

## 🔌 Подключение скриптов

Для работы скриптов оптимизации и погоды нужно добавить их вызов в `bind_stalker.script`:

```lua
-- В начале файла добавьте:
dofile("scripts/optimization.script")
dofile("scripts/weather_manager.script")

-- В функции actor_binder:update(delta_time) добавьте:
if optimization and optimization.update then
    optimization.update(delta_time)
end

if weather_manager and weather_manager.update then
    weather_manager.update(delta_time)
end
```

## ⚠️ Известные ограничения

1. **Оригинальный движок X-Ray** не поддерживает:
   - Многопоточность (требуется OGSR/OpenXRay)
   - Некоторые параметры рендера из render.ltx
   - Прямое управление памятью

2. **Шейдеры** требуют интеграции в основной pipeline рендерера

3. **PBR** полноценно работает только в R3/R4 рендере

---

## 🛠️ Решение проблем

### Игра вылетает при запуске:
- Проверьте версию игры (требуется 1.0006)
- Удалите другие моды на графику
- Используйте пресет Low

### Низкий FPS:
- Примените пресет Low или Medium
- Отключите r3_ssao и r3_gi в render.ltx
- Уменьшите r__detail_density до 0.3

### Вылеты при сохранении:
- Убедитесь, что скрипт optimization.script подключен
- Не сохраняйтесь в бою
- Используйте быстрые сохранения (F5)
