# SoC Next-Gen Fix

Мод для S.T.A.L.K.E.R.: Shadow of Chernobyl, направленный на оптимизацию, стабильность и улучшение графики.

## 📋 Описание

Этот мод решает основные проблемы оригинальной игры:
- **Оптимизация и стабильность** - исправление утечек памяти, вылетов, оптимизация рендера
- **Реалистичная графика** - современные шейдеры, улучшенная погода, HD текстуры
- **Производительность** - LOD оптимизация, кэширование текстур, оптимизация растительности

## 🔧 Требования

- S.T.A.L.K.E.R.: Shadow of Chernobyl (оригинальная версия)
- Рекомендуется использовать с движком **OGSR Engine** или **OpenXRay** для лучшей совместимости
- Минимум 4GB RAM, рекомендуется 8GB+
- Видеокарта с поддержкой DirectX 11 или выше

## 📦 Установка

1. Скопируйте папку `gamedata` в директорию с игрой
2. При использовании OGSR Engine/OpenXRay - настройте параметры в лаунчере
3. Запустите игру

## ⚙️ Настройка

### Основные конфигурационные файлы

- `gamedata/configs/render.ini` - настройки рендера и производительности
- `gamedata/configs/environment/weather.ltx` - настройки погоды
- `gamedata/configs/creatures/monsters.ltx` - оптимизация монстров
- `gamedata/scripts/optimization.script` - скрипты оптимизации

### Рекомендуемые настройки для разных систем

#### Слабые ПК (2-4 GB RAM, старая видеокарта)
```ini
; В render.ini
r__detail_density 0.3
r__vis_distance 0.6
r__wallmark_ttl 50
r__tf_screenshot FALSE
```

#### Средние ПК (8 GB RAM, GTX 1050/1060)
```ini
; В render.ini
r__detail_density 0.5
r__vis_distance 0.8
r__wallmark_ttl 100
r__tf_screenshot TRUE
```

#### Мощные ПК (16+ GB RAM, RTX 2060+)
```ini
; В render.ini
r__detail_density 0.8
r__vis_distance 1.0
r__wallmark_ttl 200
r__tf_screenshot TRUE
```

## 🎯 Особенности мода

### 1. Оптимизация и стабильность

#### Исправление утечек памяти
- Автоматическая очистка неиспользуемых ресурсов
- Оптимизация загрузки текстур
- Фикс вылетов при сохранении/загрузке

#### Оптимизация рендера
- Отключение ненужных эффектов постобработки
- Улучшенная многопоточность
- Чистка конфигов от неиспользуемых ресурсов

### 2. Реалистичная графика

#### Шейдеры
- PBR (Physically Based Rendering) для реалистичных материалов
- Улучшенные тени с мягкими краями
- God Rays (лучи света)

#### Погода
- Объемный туман
- Динамические облака
- Эффекты дождя и мокрых поверхностей

#### Текстуры
- Поддержка HD текстур (2K/4K)
- Оптимизированное сжатие для экономии видеопамяти

### 3. Производительность

- LOD оптимизация для плавного перехода детализации
- Оптимизированная растительность
- Кэширование текстур

## 🛠️ Технические детали

### Структура файлов

```
gamedata/
├── configs/
│   ├── environment/     # Настройки погоды и атмосферы
│   ├── creatures/       # Настройки существ и монстров
│   ├── weapons/         # Настройки оружия
│   └── items/           # Настройки предметов
├── shaders/             # Пользовательские шейдеры
├── scripts/             # Скрипты оптимизации
├── textures/            # HD текстуры
└── sounds/              # Улучшенные звуки
```

### Совместимость

- ✅ Совместим с OGSR Engine
- ✅ Совместим с OpenXRay
- ⚠️ Требуется адаптация для других движков
- ❌ Не совместим с модами, изменяющими те же файлы

## 📝 Известные проблемы

1. При использовании HD текстур может потребоваться больше видеопамяти
2. Некоторые эффекты могут не работать на старых видеокартах
3. Рекомендуется делать чистую установку перед использованием мода
