# История изменений SoC Next-Gen Fix

## Версия 1.0.0 (Текущая)

### ✨ Новые возможности

#### Оптимизация и стабильность
- Lua-скрипт оптимизации памяти с автоматической очисткой кэша
- Фикс вылетов при сохранении через обёртку с обработкой ошибок
- Мониторинг битых объектов в памяти
- Оптимизация AI (обновление только близких NPC)

#### Графика
- PBR шейдеры для R3 рендера (Physically Based Rendering)
- God Rays (лучи света) через пост-процесс
- SSAO (Screen Space Ambient Occlusion)
- Эффекты мокрых поверхностей для дождя
- Улучшенные тени и освещение

#### Погода
- Динамическая смена погоды через Lua-скрипт
- 4 сезона с уникальными параметрами (весна, лето, осень, зима)
- Реалистичный туман и облака
- Настройки погоды для ясной и дождливой погоды

#### Монстры
- Сбалансированные параметры для 18+ типов монстров
- Реальные параметры X-Ray движка (health, damage, attack_speed и др.)
- Поддержка множителей статов через скрипт

#### Конфигурация
- 4 пресета графики (Low, Medium, High, Default)
- Правильный формат .ltx файлов
- Только рабочие параметры движка X-Ray
- Комментарии на русском языке

### 📁 Файлы мода

**Конфигурация:**
- `gamedata/configs/render.ltx` — основные настройки рендера
- `gamedata/configs/render_low.ltx` — пресет для слабых ПК
- `gamedata/configs/render_medium.ltx` — пресет для средних ПК

- `gamedata/configs/system.ltx` — системные настройки (справочник)

**Скрипты:**
- `gamedata/scripts/optimization.script` — оптимизация памяти и AI
- `gamedata/scripts/weather_manager.script` — менеджер погоды и сезонов

**Шейдеры:**
- `gamedata/shaders/r3_pbr.s` — PBR шейдеры для R3

**Документация:**
- `README.md` — основная информация о моде
- `docs/INSTALLATION_GUIDE.md` — подробное руководство по установке
- `docs/CHANGELOG.md` — история изменений (этот файл)

## Известные проблемы

### Текущие ограничения

1. **Оригинальный движок X-Ray**
   - Многопоточность не поддерживается (требуется OGSR/OpenXRay)
   - Некоторые параметры render.ltx игнорируются
   - Прямое управление памятью ограничено

2. **Шейдеры**
   - Требуют ручной интеграции в r3_base.s
   - PBR работает не со всеми материалами
   - God Rays могут вызывать артефакты

3. **Скрипты**
   - Требуется модификация bind_stalker.script
   - Некоторые функции API недоступны в оригинале
   - Возможны микрофризы при сборке мусора

### Рабочие решения

- Используйте OGSR Engine для полной поддержки функций
- Применяйте 4GB Patch для стабильности
- Выбирайте правильный пресет графики
- Подключайте скрипты оптимизации

## Как сообщить об ошибке

При обнаружении бага:

1. **Опишите проблему**
   - Что произошло?
   - Когда произошло?
   - Какие действия привели к проблеме?

2. **Приложите логи**
   - `xray_error.log` из папки логов
   - Скриншоты (если применимо)

3. **Укажите конфигурацию**
   - Версия игры
   - Версия мода
   - Конфигурация ПК (CPU, GPU, RAM)
   - Используемый пресет графики

4. **Отправьте отчёт**
   - Через GitHub Issues
   - На форуме GSC
   - В Discord сервере
