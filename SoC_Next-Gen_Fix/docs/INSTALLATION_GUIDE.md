# Руководство по установке SoC Next-Gen Fix

## 📋 Быстрый старт

### 1. Проверка версии игры
Убедитесь, что у вас установлена **S.T.A.L.K.E.R.: Shadow of Chernobyl версии 1.0006**.

Проверить версию можно:
- В главном меню игры (внизу экрана)
- Через файл `fsgame.ltx` в папке с игрой

### 2. Резервное копирование
Перед установкой мода создайте резервную копию:
```
Скопируйте папку gamedata (если есть) в безопасное место
```

### 3. Установка мода
1. Распакуйте архив с модом
2. Скопируйте папку `gamedata` в директорию с игрой:
   ```
   C:\Games\S.T.A.L.K.E.R. - Shadow of Chernobyl\
   ```
3. Подтвердите замену файлов при необходимости

## 🔧 Расширенная установка (рекомендуется)

### Шаг 1: Установка оптимизированного движка

#### Вариант A: OGSR Engine (рекомендуется)
1. Скачайте последнюю версию с GitHub: https://github.com/OGSR/OGSR-Engine
2. Распакуйте в папку с игрой
3. Следуйте инструкциям из README

**Преимущества OGSR:**
- ✅ Многопоточность
- ✅ DirectX 11 поддержка
- ✅ Исправленные вылеты
- ✅ Улучшенная стабильность

#### Вариант B: OpenXRay
1. Скачайте с GitHub: https://github.com/OpenXRay/xray-16
2. Распакуйте в папку с игрой
3. Следуйте инструкциям из README

**Преимущества OpenXRay:**
- ✅ Открытый исходный код
- ✅ Активная разработка
- ✅ Совместимость с модами

### Шаг 2: Применение 4GB Patch

Оригинальный движок использует только 2GB RAM. Для использования 4GB:

1. Скачайте 4GB Patch: https://ntcore.com/?page_id=371
2. Запустите программу
3. Выберите файл `xrEngine.exe` в папке с игрой
4. Нажмите "Patch"
5. Готово!

### Шаг 3: Настройка графики

Выберите пресет в зависимости от вашей видеокарты:

| Видеокарта | VRAM | Пресет | Файл |
|------------|------|--------|------|
| GTX 750 Ti / R7 260X | 2GB | Low | `render_low.ltx` |
| GTX 1060 / RX 580 | 3-4GB | Medium | `render_medium.ltx` |
| GTX 1070 / RX Vega | 4-6GB | High | `render_high.ltx` |
| RTX 2060+ / RX 5700+ | 6GB+ | High/Ultra | `render_high.ltx` |

**Как применить пресет:**
1. Откройте файл пресета (например, `render_low.ltx`)
2. Выделите и скопируйте всё содержимое секции `[render]`
3. Откройте `render.ltx`
4. Замените содержимое секции `[render]` на скопированное
5. Сохраните файл

## 🔌 Подключение Lua-скриптов (опционально)

Для работы расширенной оптимизации и динамической погоды нужно подключить скрипты.

### Файл: `gamedata/scripts/bind_stalker.script`

1. Откройте файл `bind_stalker.script` в текстовом редакторе
2. Найдите начало файла (после заголовков)
3. Добавьте строки:
   ```lua
   dofile("scripts/optimization.script")
   dofile("scripts/weather_manager.script")
   ```

4. Найдите функцию `actor_binder:update(delta_time)`
5. Внутри функции добавьте:
   ```lua
   function actor_binder:update(delta_time)
       -- Существующий код...
       
       -- Добавленные строки:
       if optimization and optimization.update then
           optimization.update(delta_time)
       end
       
       if weather_manager and weather_manager.update then
           weather_manager.update(delta_time)
       end
       
       -- Остальной существующий код...
   end
   ```

6. Сохраните файл

**Примечание:** Если вы не уверены в своих действиях, пропускайте этот шаг. Базовая оптимизация работает без подключения скриптов.

## ❗ Решение проблем

### Игра не запускается

**Причина 1:** Неправильная версия игры
- Решение: Установите патч 1.0006

**Причина 2:** Конфликт с другими модами
- Решение: Удалите другие моды на графику

**Причина 3:** Повреждённые файлы
- Решение: Проверьте целостность файлов в Steam/GSC Launcher

### Вылеты при загрузке локации

**Причина:** Нехватка памяти
- Решение 1: Примените 4GB Patch
- Решение 2: Используйте пресет Low
- Решение 3: Установите OGSR Engine

### Низкий FPS

**Причина 1:** Высокие настройки графики
- Решение: Используйте пресет Low или Medium

**Причина 2:** Старый драйвер видеокарты
- Решение: Обновите драйверы NVIDIA/AMD

**Причина 3:** Фоновые процессы
- Решение: Закройте браузер, Discord и другие приложения

### Вылеты при сохранении

**Причина:** Битые объекты в памяти
- Решение 1: Подключите скрипт optimization.script
- Решение 2: Не сохраняйтесь во время боя
- Решение 3: Используйте быстрые сохранения (F5/F9)

### Чёрный экран после загрузки

**Причина:** Проблемы с шейдерами
- Решение 1: Удалите папку `shaders` из gamedata
- Решение 2: Переключитесь на R2 рендер в настройках
- Решение 3: Обновите драйверы видеокарты

## 📊 Диагностика

### Проверка работы мода

1. Запустите игру
2. Откройте консоль (~)
3. Введите команду: `stat fps`
4. Проверьте FPS и время рендера

### Логи игры

Файлы логов находятся в:
```
C:\Users\[Имя]\AppData\Local\STALKER-SOC\logs\
```

Основные файлы:
- `xray_[дата].log` — основной лог
- `xray_error.log` — логи ошибок

### Отправка отчёта об ошибке

При сообщении о проблеме приложите:
1. Версию игры
2. Версию мода
3. Конфигурацию ПК (CPU, GPU, RAM)
4. Файл `xray_error.log`
5. Описание действий перед вылетом

## 🔄 Обновление мода

### С предыдущей версии

После обновления верните эти файлы на место.
