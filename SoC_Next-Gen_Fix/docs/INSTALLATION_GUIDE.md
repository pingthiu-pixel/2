## 🔧 Требования

### Минимальные
- **Игра:** S.T.A.L.K.E.R.: Shadow of Chernobyl (оригинальная версия 1.0004)
- **ОС:** Windows 7/8/10/11 (64-bit)
- **Процессор:** Intel Core i3 / AMD FX-4300
- **ОЗУ:** 4 GB
- **Видеокарта:** NVIDIA GTX 750 Ti / AMD Radeon R7 260X (2GB VRAM)
- **DirectX:** Версия 11
- **Место на диске:** 15 GB свободной памяти

### Рекомендуемые
- **ОС:** Windows 10/11 (64-bit)
- **Процессор:** Intel Core i5-8400 / AMD Ryzen 5 2600
- **ОЗУ:** 8-16 GB
- **Видеокарта:** NVIDIA GTX 1060 6GB / AMD RX 580 (для средних настроек)
- **Видеокарта:** NVIDIA RTX 2060 / AMD RX 5700 (для высоких настроек)
- **DirectX:** Версия 11/12
- **SSD:** Рекомендуется для быстрой загрузки

### Для максимальной графики
- **Процессор:** Intel Core i7-9700K / AMD Ryzen 7 3700X
- **ОЗУ:** 16-32 GB
- **Видеокарта:** NVIDIA RTX 3070 / AMD RX 6800 XT или выше
- **VRAM:** 8GB+ для HD текстур

## 📦 Подготовка

### Шаг 1: Проверка версии игры
1. Запустите игру
2. В главном меню посмотрите версию в нижнем правом углу
3. Должна быть версия **1.0004** (оригинальная SoC)
4. Если у вас другая версия, скачайте патч до 1.0004

### Шаг 2: Чистая установка (рекомендуется)
```
1. Сделайте резервную копию сохранений:
   %USERPROFILE%\Documents\S.T.A.L.K.E.R.-Shadow of Chernobyl\savedgames\

2. Удалите предыдущие моды (если есть):
   - Папка gamedata в директории игры
   - Файлы .dll в корне игры

3. Проверьте целостность файлов игры через Steam/GOG
```

### Шаг 3: Выбор движка (опционально, но рекомендуется)

#### Вариант A: OGSR Engine (Рекомендуется)
```
1. Скачайте последнюю версию с GitHub:
   https://github.com/OpenXRay/xray-16/releases

2. Распакуйте в папку с игрой

3. Настройте лаунчер OGSR
```

#### Вариант B: OpenXRay
```
1. Скачайте с официального сайта:
   https://github.com/OpenXRay/xray-16

2. Установите следуя инструкциям

3. Выберите профиль SoC
```

#### Вариант C: Оригинальный движок
```
Работает, но с ограниченной поддержкой новых функций
Требуется DirectX 11 патч
```

## 📥 Установка

### Быстрая установка

1. **Скопируйте папку `gamedata`** из архива мода
2. **Вставьте в директорию игры** (где находится fsgame.ltx)
3. **Готово!**

Полный путь должен выглядеть так:
```
S.T.A.L.K.E.R. - Shadow of Chernobyl\
├── gamedata\           <-- Сюда копировать
│   ├── configs\
│   ├── scripts\
│   ├── shaders\
│   └── textures\
├── fsgame.ltx
├── xrCore.dll
└── ...
```

### Подробная установка по шагам

#### Шаг 1: Копирование файлов
```
1. Откройте папку с модом
2. Скопируйте всю папку "gamedata"
3. Перейдите в папку с игрой
4. Вставьте папку "gamedata"
5. Подтвердите замену файлов если потребуется
```

#### Шаг 2: Настройка fsgame.ltx (если нужно)
Откройте файл `fsgame.ltx` в блокноте и убедитесь что есть строка:
```
$game_data$            true|       false|      $fs_root$\gamedata\
```

#### Шаг 3: Настройка движка
Если используете OGSR/OpenXRay:
```
1. Откройте лаунчер движка
2. Выберите профиль "SoC Next-Gen"
3. Настройте параметры графики
4. Сохраните настройки
```

#### Шаг 4: Первый запуск
```
1. Запустите игру через лаунчер
2. В главном меню выберите "Опции"
3. Настройте графику согласно вашим предпочтениям
4. Сохраните и начните новую игру
```

## ⚙️ Настройка

### Настройки графики в игре

#### Для слабых ПК (30-40 FPS)
```
Разрешение: 1920x1080 или ниже
Рендер: Static (R1) или Object (R2)
Качество текстур: Среднее
Качество теней: Низкое
Дальность прорисовки: 50%
Трава: Отключена или Низкая
```

#### Для средних ПК (50-60 FPS)
```
Разрешение: 1920x1080
Рендер: Enhanced (R3)
Качество текстур: Высокое
Качество теней: Среднее
Дальность прорисовки: 75%
Трава: Средняя
God Rays: Включено
SSAO: Включено
```

#### Для мощных ПК (60+ FPS)
```
Разрешение: 2560x1440 или 4K
Рендер: Advanced (R4/DX11)
Качество текстур: Ультра (HD)
Качество теней: Высокое
Дальность прорисовки: 100%
Трава: Высокая
God Rays: Высокое
SSAO: Высокое
PBR шейдеры: Включено
```

### Ручная настройка render.ini

Откройте `gamedata/configs/render.ini` и отредактируйте:

```ini
[render]
; Для экономии видеопамяти
r__texture_memory_limit = 2048    ; 2GB для 4GB VRAM
                                    4096 для 8GB VRAM

; Для лучшей производительности
r__detail_density = 0.5           ; Меньше = быстрее
r__vis_distance = 0.7             ; Дистанция видимости

; Отключение эффектов для FPS
r__godrays_enabled = FALSE        ; Отключить лучи света
r__ssao_enabled = FALSE           ; Отключить SSAO
r__bloom_enabled = FALSE          ; Отключить свечение
```

### Настройка под конкретные локации

Для проблемных локаций (Янов, Припять):
```ini
[render_override]
; Специальные настройки для тяжелых локаций
jupiter_override_density = 0.4
pripyat_override_vis = 0.6
```

## 🔧 Решение проблем

### Игра не запускается

**Проблема:** Черный экран при запуске
```
Решение:
1. Обновите драйверы видеокарты
2. Установите DirectX End-User Runtime
3. Попробуйте режим совместимости Windows 7
4. Запустите от имени администратора
```

**Проблема:** Вылет сразу после запуска
```
Решение:
1. Проверьте целостность файлов игры
2. Удалите другие моды
3. Убедитесь что версия игры 1.0004
4. Проверьте логи в _appdata_\logs\
```

### Низкий FPS

**Проблема:** Менее 30 FPS
```
Решение:
1. Откройте render.ini
2. Установите r__detail_density = 0.3
3. Установите r__vis_distance = 0.5
4. Отключите godrays и SSAO
5. Уменьшите разрешение текстур
6. Используйте профиль [render_low]
```

### Вылеты во время игры

**Проблема:** Вылет при сохранении
```
Решение:
1. Мод уже включает фикс сохранений
2. Не сохраняйтесь во время боя
3. Делайте сохранения в разных слотах
4. Очищайте старые сохранения
```

**Проблема:** Вылет при переходе между локациями
```
Решение:
1. Подождите полной загрузки перед переходом
2. Проверьте оперативную память (минимум 4GB)
3. Закройте фоновые приложения
4. Увеличьте файл подкачки
```

### Графические артефакты

**Проблема:** Мерцание текстур
```
Решение:
1. Обновите драйверы видеокарты
2. Отключите анизотропную фильтрацию в драйвере
3. Установите r__texture_cache = TRUE
```

**Проблема:** Пропавшие тени
```
Решение:
1. Проверьте r__shadow_quality в render.ini
2. Убедитесь что рендер поддерживает тени (R2+)
3. Переустановите шейдеры
```

### Проблемы со звуком

**Проблема:** Пропадает звук
```
Решение:
1. Проверьте настройки звука в игре
2. Обновите аудиодрайверы
3. Отключите EAX в настройках
4. Установите OpenAL Soft
```

## ❓ FAQ

**В: Совместим ли мод с другими модами?**
О: Мод может конфликтовать с модами изменяющими те же файлы. 
   Используйте порядок загрузки и проверяйте совместимость.

**В: Можно ли использовать старые сохранения?**
О: Рекомендуется начать новую игру. Старые сохранения могут работать, 
   но возможны проблемы со скриптами.

**В: Почему игра вылетает на локации X?**
О: Проверьте логи вылета в _appdata_\logs\. Чаще всего проблема 
   решается обновлением драйверов или снижением настроек.

**В: Как включить трассировку лучей?**
О: Требуется RTX видеокарта и OGSR Engine с поддержкой DXR.
   Настройте в лаунчере OGSR.

**В: Мод работает с Anomaly/GAMMA?**
О: Нет, это отдельная сборка для оригинальной SoC.
   Для Anomaly смотрите соответствующие моды.

**В: Как обновить мод?**
О: Скачайте новую версию и замените файлы в папке gamedata.
   Сделайте бэкап конфигов если меняли настройки.

**В: Где взять HD текстуры?**
О: В папке gamedata/textures идут базовые текстуры.
   Для полноценных HD паков смотрите рекомендации в README.
